Cómo funciona

Inicie una comparación

Pegue las dos entradas que desea comparar en los editores izquierdo y derecho, o arrastre un archivo a cada editor. Compruebe el formato seleccionado en cada lado y pulse Comparar. Para probar la herramienta, use cargar ejemplo debajo de Comparar. Formatear y Limpiar solo afectan al editor correspondiente.

Qué compara la herramienta

La herramienta compara los valores interpretados, no las líneas originales del texto. Ignora el formato, el orden de las propiedades de los objetos y el orden de los elementos de los arrays, incluso en estructuras anidadas. Los duplicados siguen contando. Los objetos de los arrays se alinean mediante campos identificadores o su contenido para facilitar la lectura de los cambios.

Lea el resultado

El diff usa la entrada izquierda como referencia: el rojo indica eliminaciones y el verde adiciones necesarias para llegar a la entrada derecha. Los valores diferentes aparecen como una eliminación y una adición, con énfasis en el fragmento que difiere. Esta dirección es una convención visual; las entradas no tienen que representar versiones anteriores y posteriores. El resultado muestra datos normalizados, por lo que el orden y el formato pueden diferir de las entradas. Un resultado equivalente significa que no se encontraron diferencias según estas reglas; los textos originales pueden seguir siendo distintos. Pulse Volver para editar las entradas de nuevo.

Elija el formato de las entradas

Cada editor acepta JSON, JSONL o un subconjunto limitado de YAML. JSONL requiere un valor JSON completo por línea no vacía; se omiten las líneas en blanco y los registros se comparan como un array, sin considerar su orden. Si ambos lados usan el mismo formato, el resultado se muestra en ese formato. Si usan formatos diferentes, se comparan los valores interpretados y el resultado se muestra en JSON. No se conservan los comentarios ni el formato original.

Cuándo importa el orden

La herramienta resulta útil para comparar respuestas de API, datos de configuración y colecciones sin orden definido. No es adecuada para comprobar cambios en secuencias, clasificaciones o historiales donde la posición tiene significado: cambiar solo el orden no produce diferencias. En esos casos, use una comparación que tenga en cuenta el orden.

Otras limitaciones

El soporte de YAML cubre mapeos, secuencias y colecciones simples comunes; no implementa toda la especificación YAML. Para YAML complejo, convierta los documentos a JSON con un analizador completo de YAML antes de comparar. Los números usan la precisión de JavaScript: los enteros muy grandes pueden perder dígitos, por lo que conviene representar identificadores exactos como cadenas. Las entradas grandes pueden ralentizar el navegador o superar la memoria disponible.

Ejemplos

Mismo contenido

Las entradas son equivalentes: las propiedades y los elementos del array cambiaron de orden, pero los valores y sus cantidades son iguales.

Izquierda
{"a": 1, "b": [1, 2]}
Derecha
{"b": [2, 1], "a": 1}

Valores diferentes

El mismo campo tiene valores diferentes: 10 a la izquierda y 20 a la derecha. La comparación resalta la diferencia de valor aunque la estructura sea la misma.

Izquierda
{"value": 10}
Derecha
{"value": 20}

Cantidades diferentes

El número 1 aparece dos veces a la izquierda y una a la derecha. Ignorar el orden del array no significa ignorar cuántas veces aparece cada valor.

Izquierda
[1, 1, 2]
Derecha
[1, 2]
