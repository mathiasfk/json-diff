Perguntas frequentes

Como funciona a comparação?

Em vez de realizar um diff baseado apenas em texto, o Smart JSON Diff faz uma comparação semântica. Ele normaliza as duas entradas ordenando alfabeticamente as propriedades dos objetos e alinhando de forma inteligente os elementos dos arrays. Quando os dois arrays contêm uma chave única, os elementos são alinhados por essa chave; caso contrário, são comparados pelo conteúdo normalizado para minimizar o ruído e destacar apenas as diferenças mais relevantes. A comparação é executada inteiramente no seu navegador, usando o jsondiffpatch internamente.

Como o Smart JSON Diff é diferente de outras ferramentas de comparação de JSON?

Muitas ferramentas tradicionais de comparação de JSON tratam arrays como sequências, o que significa que a ordem dos elementos afeta o resultado. O Smart JSON Diff trata os elementos dos arrays como um multiconjunto, ou seja, a ordem dos elementos não importa, mas elementos duplicados continuam sendo considerados.

Esquerda
[1, 2, 3]
Direita
[3, 2, 1]

Equivalentes: os valores são os mesmos, apesar da ordem.

O que significam as cores na comparação?

Verde indica adições e vermelho indica remoções. Toda a linha alterada é destacada, enquanto o trecho exato que mudou recebe um destaque mais intenso.

A ordem das propriedades afeta o resultado?

Não. As propriedades são ordenadas alfabeticamente antes da comparação, portanto, objetos com o mesmo conteúdo, mas com propriedades em uma ordem diferente, são considerados equivalentes.

Esquerda
{"a": 1, "b": 2}
Direita
{"b": 2, "a": 1}

Equivalentes: a ordem das propriedades não afeta a comparação.

A ordem dos arrays afeta o resultado?

Não. O Smart JSON Diff encontra automaticamente a melhor forma de alinhar os elementos dos arrays, portanto, arrays que contêm os mesmos elementos em uma ordem diferente são considerados equivalentes.

Esquerda
[
  {
    "id": 1,
    "name": "Ana"
  },
  {
    "id": 2,
    "name": "Sam"
  }
]
Direita
[
  {
    "id": 2,
    "name": "Sam"
  },
  {
    "id": 1,
    "name": "Ana"
  }
]

Equivalentes: cada objeto mantém seus valores, apesar da ordem diferente no array.

Como as diferenças entre arrays são tratadas?

O Smart JSON Diff encontra um alinhamento que maximiza a similaridade entre as duas versões. Quando os dois arrays contêm uma chave única, os elementos são alinhados por essa chave; caso contrário, são alinhados pelo conteúdo normalizado. Isso ajuda a minimizar o ruído e destacar as alterações mais relevantes. Reordenar os mesmos elementos não produz nenhuma diferença, enquanto elementos adicionados, removidos ou modificados continuam sendo detectados.

O que acontece com duplicatas e valores alterados?

Elementos duplicados continuam contando, e valores diferentes são detectados mesmo quando a estrutura é a mesma.

Esquerda
[1, 1, 2]
Direita
[1, 2]

Diferentes: o lado esquerdo contém uma ocorrência a mais do número 1.

Esquerda
{"value": 10}
Direita
{"value": 20}

Diferentes: o campo contém 10 à esquerda e 20 à direita.

É seguro colar dados confidenciais?

A comparação ocorre no navegador. Entradas e resultados podem permanecer no localStorage; consulte a página de privacidade sobre armazenamento e serviços externos.
