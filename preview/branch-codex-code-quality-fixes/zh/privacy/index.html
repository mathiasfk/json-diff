隐私

比较在浏览器中进行。工具将输入文本、所选格式、视图状态和比较结果保存在 localStorage 中以便恢复；语言选择也保存在此。可在浏览器中清除网站数据以移除这些内容。所选数组比较模式也会被保存。

本网站使用 Google Analytics，并发送操作、格式、输入字符数和部分文件元数据（包括被拒绝文件的名称）等使用事件；事件代码不会发送输入文本。加载 Analytics 时 Google 会收到请求。编辑器也可能从 CDN 加载资源。输入敏感信息前，请考虑浏览器、扩展和设备的情况。 GitHub Pages 托管也会产生对 GitHub 的请求。目前不会加载广告。
