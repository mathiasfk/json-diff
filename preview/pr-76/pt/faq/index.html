Perguntas frequentes

Como funciona a comparação?

A ferramenta compara valores interpretados e ordena as propriedades dos objetos. O alinhamento automático associa itens semelhantes; Comparar por posição compara os mesmos índices recursivamente. A comparação ocorre no navegador.

Como o Smart JSON Diff é diferente de outras ferramentas de comparação de JSON?

O alinhamento automático ignora a ordem dos arrays, mas conta duplicatas. Também é possível comparar por posição quando a ordem importa.

Esquerda
[1, 2, 3]
Direita
[3, 2, 1]

Equivalente no alinhamento automático: os valores e suas quantidades não mudaram.

O que significam as cores na comparação?

Verde indica adições e vermelho indica remoções. Toda a linha alterada é destacada, enquanto o trecho exato que mudou recebe um destaque mais intenso.

A ordem das propriedades afeta o resultado?

Não. As propriedades são ordenadas alfabeticamente antes da comparação, portanto, objetos com o mesmo conteúdo, mas com propriedades em uma ordem diferente, são considerados equivalentes.

Esquerda
{"a": 1, "b": 2}
Direita
{"b": 2, "a": 1}

Equivalentes: a ordem das propriedades não afeta a comparação.

A ordem dos arrays afeta o resultado?

No alinhamento automático (padrão), apenas a ordem não altera o resultado. Comparar por posição considera mudanças de ordem como diferenças.

Esquerda
[
  {
    "id": 1,
    "name": "Ana"
  },
  {
    "id": 2,
    "name": "Sam"
  }
]
Direita
[
  {
    "id": 2,
    "name": "Sam"
  },
  {
    "id": 1,
    "name": "Ana"
  }
]

Equivalente no alinhamento automático: os valores e suas quantidades não mudaram.

Como as diferenças entre arrays são tratadas?

O alinhamento automático associa itens semelhantes por identificadores ou conteúdo. Comparar por posição compara itens no mesmo índice, inclusive em arrays aninhados.

O que acontece com duplicatas e valores alterados?

Elementos duplicados continuam contando, e valores diferentes são detectados mesmo quando a estrutura é a mesma.

Esquerda
[1, 1, 2]
Direita
[1, 2]

Diferentes: o lado esquerdo contém uma ocorrência a mais do número 1.

Esquerda
{"value": 10}
Direita
{"value": 20}

Diferentes: o campo contém 10 à esquerda e 20 à direita.

É seguro colar dados confidenciais?

A comparação ocorre no navegador. Entradas e resultados podem permanecer no localStorage; consulte a página de privacidade sobre armazenamento e serviços externos.
