FAQ

How does the comparison work?

Instead of a naive text-based diff, Smart JSON Diff performs a semantic comparison. It normalizes both inputs by sorting object properties alphabetically and intelligently aligns array items. When both arrays contain a unique key, items are aligned by that key; otherwise, items are matched by normalized content to minimize noise and surface only the most relevant differences. The comparison runs entirely in your browser using jsondiffpatch under the hood.

How is Smart JSON Diff different from other JSON diff tools?

Many traditional JSON diff tools treat arrays as sequences, meaning that item order affects the comparison. Smart JSON Diff treats array items as a multiset, meaning that item order does not matter while duplicate items still count.

Left
[1, 2, 3]
Right
[3, 2, 1]

Equivalent: the values are the same, despite their order.

What do the colors mean in the diff?

Green indicates additions and red indicates removals. The entire changed line is highlighted, while the exact changed segment is emphasized more strongly.

Does property order affect the result?

No. Properties are sorted alphabetically before comparison, so objects with the same content but different key order are considered equivalent.

Left
{"a": 1, "b": 2}
Right
{"b": 2, "a": 1}

Equivalent: property order does not affect the comparison.

Does array order affect the result?

No. Smart JSON Diff automatically finds the best way to align array items, so arrays containing the same items in a different order are considered equivalent.

Left
[
  {
    "id": 1,
    "name": "Ana"
  },
  {
    "id": 2,
    "name": "Sam"
  }
]
Right
[
  {
    "id": 2,
    "name": "Sam"
  },
  {
    "id": 1,
    "name": "Ana"
  }
]

Equivalent: each object keeps its values, despite the different array order.

How are array differences handled?

Smart JSON Diff finds an alignment that maximizes similarity between the two versions. When both arrays contain a unique key, items are aligned by that key; otherwise, items are aligned by normalized content, helping minimize noise and highlight the most relevant changes. Reordering the same items produces no diff, while added, removed, or changed items are still detected.

What happens to duplicates and changed values?

Duplicate items count, and different values are detected even when the structure is the same.

Left
[1, 1, 2]
Right
[1, 2]

Different: the left side contains one more occurrence of 1.

Left
{"value": 10}
Right
{"value": 20}

Different: the field contains 10 on the left and 20 on the right.

Is it safe to paste sensitive data?

The comparison runs in your browser. Inputs and results may remain in localStorage; see the privacy page for storage and external services.
