Como funciona

Comece uma comparação

Cole as duas entradas que deseja comparar nos editores esquerdo e direito, ou arraste um arquivo para cada editor. Confira o formato selecionado de cada lado e clique em Comparar. Para experimentar primeiro, use carregar exemplo abaixo de Comparar. Formatar e Limpar afetam apenas o editor correspondente.

O que a ferramenta compara

A ferramenta compara os valores interpretados, em vez das linhas originais do texto. Ela ignora a formatação, a ordem das propriedades dos objetos e a ordem dos elementos dos arrays, inclusive em estruturas aninhadas. Elementos duplicados continuam contando. Objetos em arrays são alinhados por campos identificadores ou pelo conteúdo para facilitar a leitura das alterações.

Leia o resultado

O diff usa a entrada esquerda como referência: vermelho indica remoções e verde indica adições necessárias para chegar à entrada direita. Valores diferentes aparecem como remoção e adição, com destaque no trecho que difere. Essa direção é uma convenção de exibição; as entradas não precisam representar versões anteriores e posteriores. O resultado mostra dados normalizados, portanto a ordem e a formatação podem ser diferentes das entradas. Um resultado equivalente significa que não foram encontradas diferenças segundo essas regras de comparação; os textos originais ainda podem ser diferentes. Clique em Voltar para editar as entradas novamente.

Escolha o formato das entradas

Cada editor aceita JSON, JSONL ou um subconjunto limitado de YAML. JSONL exige um valor JSON completo por linha não vazia; linhas em branco são ignoradas e os registros são comparados como um array, sem considerar a ordem. Se os dois lados usarem o mesmo formato, o resultado será exibido nesse formato. Se usarem formatos diferentes, os valores interpretados serão comparados e o resultado será exibido em JSON. Comentários e formatação original não são preservados.

Quando a ordem importa

A ferramenta é útil para comparar respostas de APIs, dados de configuração e coleções sem ordem definida. Ela não é adequada para verificar alterações em sequências, rankings ou históricos nos quais a posição tem significado: uma simples reordenação não produz diferença. Nesses casos, use uma comparação que considere a ordem.

Outras limitações

O suporte a YAML cobre mapeamentos, sequências e coleções simples comuns; não implementa toda a especificação YAML. Para YAML complexo, converta os documentos para JSON com um parser completo de YAML antes de comparar. Os números usam a precisão do JavaScript: inteiros muito grandes podem perder dígitos, portanto represente identificadores exatos como strings. Entradas grandes podem tornar o navegador lento ou exceder a memória disponível.

Exemplos

Mesmo conteúdo

As entradas são equivalentes: as propriedades e os elementos do array mudaram de ordem, mas os valores e suas quantidades continuam iguais.

Esquerda
{"a": 1, "b": [1, 2]}
Direita
{"b": [2, 1], "a": 1}

Valores diferentes

O mesmo campo tem valores diferentes: 10 à esquerda e 20 à direita. A comparação destaca a diferença de valor, mesmo com a mesma estrutura.

Esquerda
{"value": 10}
Direita
{"value": 20}

Quantidades diferentes

O número 1 aparece duas vezes à esquerda e uma vez à direita. Ignorar a ordem do array não significa ignorar quantas vezes cada valor aparece.

Esquerda
[1, 1, 2]
Direita
[1, 2]
