使用说明

开始比较

在左右编辑器中粘贴要比较的两份数据，也可以将文件拖入各编辑器。检查两侧选择的格式，然后点击比较。若想先试用，可点击比较按钮下方的加载示例。格式化和清除仅作用于对应的编辑器。

工具比较什么

工具比较解析后的值，而不是原始文本行。它会忽略格式、对象属性顺序和数组元素顺序，包括嵌套结构中的顺序。重复元素仍会计数。数组中的对象会根据标识字段或内容对齐，方便查看修改。

阅读结果

差异视图以左侧输入为基准：红色表示得到右侧输入时需要删除的内容，绿色表示需要新增的内容。不同的值显示为删除和新增，并突出显示不同的部分。这只是显示方向的约定，两份输入不必代表先后版本。结果展示规范化后的数据，因此顺序和格式可能与输入不同。结果等价表示按照这些规则未发现差异，并不代表原始文本完全相同。点击返回可继续编辑输入。

选择输入格式

每个编辑器支持 JSON、JSONL 或有限的 YAML 子集。JSONL 的每个非空行须包含一个完整的 JSON 值；空行会被跳过，记录作为数组比较，忽略其顺序。两侧格式相同时，结果以该格式显示；格式不同时，比较解析后的值，并以 JSON 显示结果。注释和原始格式不会保留。

何时需要考虑顺序

该工具适合比较 API 响应、配置数据和无序集合。对于位置具有意义的序列、排名或历史记录，它不适合检查顺序变化：仅重新排列元素不会产生差异。这些情况应使用考虑顺序的比较方式。

其他限制

YAML 支持常见映射、序列和简单流式集合，并未实现完整的 YAML 规范。对于复杂 YAML，请先用完整的 YAML 解析器将文档转换为 JSON，再进行比较。数字受 JavaScript 精度限制：很大的整数可能丢失数字，需精确保留的标识符应使用字符串。较大的输入可能使浏览器变慢或超出可用内存。

示例

内容相同

这些输入等价：属性和数组元素的顺序不同，但值及其出现次数相同。

左侧
{"a": 1, "b": [1, 2]}
右侧
{"b": [2, 1], "a": 1}

值不同

同一字段在左侧的值为 10，右侧为 20。即使结构相同，比较仍会突出显示值的差异。

左侧
{"value": 10}
右侧
{"value": 20}

出现次数不同

数字 1 在左侧出现两次，在右侧出现一次。忽略数组顺序并不意味着忽略每个值的出现次数。

左侧
[1, 1, 2]
右侧
[1, 2]
