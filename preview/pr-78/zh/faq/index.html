常见问题

比较是如何进行的？

工具比较解析后的值并排序对象属性。自动对齐匹配相似的数组元素；按位置比较会递归比较相同索引处的元素。比较在浏览器中进行。

Smart JSON Diff 与其他 JSON Diff 工具有何不同？

自动对齐忽略数组顺序，但仍计入重复元素。顺序重要时也可按位置比较。

左侧
[1, 2, 3]
右侧
[3, 2, 1]

自动对齐时等价：值及其出现次数没有变化。

差异中的颜色是什么意思？

绿色表示新增，红色表示删除。整行发生变化时会被突出显示，而具体发生变化的部分会使用更明显的颜色进一步突出。

属性顺序会影响结果吗？

不会。比较前会按字母顺序对属性进行排序，因此内容相同但属性顺序不同的对象会被视为等价。

左侧
{"a": 1, "b": 2}
右侧
{"b": 2, "a": 1}

等价：属性顺序不影响比较。

数组顺序会影响结果吗？

自动对齐（默认）下，仅改变顺序不影响结果。按位置比较会将顺序变化视为差异。

左侧
[
  {
    "id": 1,
    "name": "Ana"
  },
  {
    "id": 2,
    "name": "Sam"
  }
]
右侧
[
  {
    "id": 2,
    "name": "Sam"
  },
  {
    "id": 1,
    "name": "Ana"
  }
]

自动对齐时等价：值及其出现次数没有变化。

数组差异是如何处理的？

自动对齐通过标识字段或内容匹配相似元素。按位置比较会比较相同索引处的元素，包括嵌套数组。

重复项和修改的值如何处理？

重复元素仍会计数，即使结构相同，不同的值也会被检测出来。

左侧
[1, 1, 2]
右侧
[1, 2]

不等价：左侧的数字 1 多出现一次。

左侧
{"value": 10}
右侧
{"value": 20}

不等价：该字段在左侧为 10，右侧为 20。

粘贴敏感数据安全吗？

比较在浏览器中进行。输入和结果可能保留在 localStorage 中；有关存储和外部服务，请参阅隐私页面。
