FAQ

How does the comparison work?

The tool compares parsed values and sorts object properties. Automatic alignment matches similar array items; Compare by position compares the same indices recursively. The comparison runs in your browser.

How is Smart JSON Diff different from other JSON diff tools?

Automatic alignment ignores array order while counting duplicates. You can also compare by position when order matters.

Left
[1, 2, 3]
Right
[3, 2, 1]

Equivalent with automatic alignment: the values and counts are unchanged.

What do the colors mean in the diff?

Green indicates additions and red indicates removals. The entire changed line is highlighted, while the exact changed segment is emphasized more strongly.

Does property order affect the result?

No. Properties are sorted alphabetically before comparison, so objects with the same content but different key order are considered equivalent.

Left
{"a": 1, "b": 2}
Right
{"b": 2, "a": 1}

Equivalent: property order does not affect the comparison.

Does array order affect the result?

With automatic alignment (the default), order alone does not affect the result. Compare by position treats changes in order as differences.

Left
[
  {
    "id": 1,
    "name": "Ana"
  },
  {
    "id": 2,
    "name": "Sam"
  }
]
Right
[
  {
    "id": 2,
    "name": "Sam"
  },
  {
    "id": 1,
    "name": "Ana"
  }
]

Equivalent with automatic alignment: the values and counts are unchanged.

How are array differences handled?

Automatic alignment matches similar items by identifying fields or content. Compare by position compares items at the same index, including nested arrays.

What happens to duplicates and changed values?

Duplicate items count, and different values are detected even when the structure is the same.

Left
[1, 1, 2]
Right
[1, 2]

Different: the left side contains one more occurrence of 1.

Left
{"value": 10}
Right
{"value": 20}

Different: the field contains 10 on the left and 20 on the right.

Is it safe to paste sensitive data?

The comparison runs in your browser. Inputs and results may remain in localStorage; see the privacy page for storage and external services.
