Privacy

Comparison happens in your browser. The tool stores input text, selected formats, view state and comparison result in localStorage so they can be restored; the language choice is stored there too. Clear site data in your browser to remove this stored information. The selected array comparison mode is stored as well.

The site uses Google Analytics and sends usage events including actions, formats, input character counts and some file metadata (including rejected file names); its event code does not send the input text. Google receives requests when Analytics loads. The editor may also load resources from a CDN. Consider your browser, extensions and device before entering sensitive information. Hosting on GitHub Pages also involves requests to GitHub. No ads are currently loaded.
