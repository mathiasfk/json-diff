常见问题

比较是如何进行的？

Smart JSON Diff 不只是进行简单的文本 Diff，而是执行语义比较。它会通过按字母顺序排列对象属性来规范化两个输入，并智能地对齐数组元素。当两个数组都包含唯一键时，元素会根据该键进行对齐；否则，会根据规范化后的内容进行匹配，以尽量减少无关差异，并突出显示最相关的变化。整个比较过程都在您的浏览器中完成，并使用 jsondiffpatch 进行底层 Diff 处理。

Smart JSON Diff 与其他 JSON Diff 工具有何不同？

许多传统的 JSON Diff 工具会将数组视为有序序列，因此元素的顺序会影响比较结果。Smart JSON Diff 将数组元素视为多重集合，这意味着元素的顺序不会影响结果，但重复元素仍会被计入。

左侧
[1, 2, 3]
右侧
[3, 2, 1]

等价：顺序不同，但值相同。

差异中的颜色是什么意思？

绿色表示新增，红色表示删除。整行发生变化时会被突出显示，而具体发生变化的部分会使用更明显的颜色进一步突出。

属性顺序会影响结果吗？

不会。比较前会按字母顺序对属性进行排序，因此内容相同但属性顺序不同的对象会被视为等价。

左侧
{"a": 1, "b": 2}
右侧
{"b": 2, "a": 1}

等价：属性顺序不影响比较。

数组顺序会影响结果吗？

不会。Smart JSON Diff 会自动找到最佳方式来对齐数组元素，因此包含相同元素但顺序不同的数组会被视为等价。

左侧
[
  {
    "id": 1,
    "name": "Ana"
  },
  {
    "id": 2,
    "name": "Sam"
  }
]
右侧
[
  {
    "id": 2,
    "name": "Sam"
  },
  {
    "id": 1,
    "name": "Ana"
  }
]

等价：数组顺序不同，但每个对象的值保持不变。

数组差异是如何处理的？

Smart JSON Diff 会寻找能够最大化两个版本相似度的对齐方式。当两个数组都包含唯一键时，元素会根据该键进行对齐；否则，会根据规范化后的内容进行对齐。这样可以尽量减少无关差异，并突出显示最相关的变化。重新排列相同的元素不会产生差异，而新增、删除或修改的元素仍然会被检测出来。

重复项和修改的值如何处理？

重复元素仍会计数，即使结构相同，不同的值也会被检测出来。

左侧
[1, 1, 2]
右侧
[1, 2]

不等价：左侧的数字 1 多出现一次。

左侧
{"value": 10}
右侧
{"value": 20}

不等价：该字段在左侧为 10，右侧为 20。

粘贴敏感数据安全吗？

比较在浏览器中进行。输入和结果可能保留在 localStorage 中；有关存储和外部服务，请参阅隐私页面。
