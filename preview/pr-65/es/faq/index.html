Preguntas frecuentes

¿Cómo funciona la comparación?

En lugar de realizar una comparación de texto simple, Smart JSON Diff realiza una comparación semántica. Normaliza ambas entradas ordenando alfabéticamente las propiedades de los objetos y alineando inteligentemente los elementos de los arrays. Cuando ambos arrays contienen una clave única, los elementos se alinean mediante esa clave; de lo contrario, se comparan mediante su contenido normalizado para minimizar el ruido y mostrar solo las diferencias más relevantes. La comparación se ejecuta completamente en su navegador y utiliza jsondiffpatch internamente.

¿En qué se diferencia Smart JSON Diff de otras herramientas de comparación JSON?

Muchas herramientas tradicionales de comparación JSON tratan los arrays como secuencias, por lo que el orden de los elementos afecta al resultado. Smart JSON Diff trata los elementos de los arrays como un multiconjunto, lo que significa que el orden de los elementos no importa, pero los elementos duplicados siguen contando.

Izquierda
[1, 2, 3]
Derecha
[3, 2, 1]

Equivalentes: los valores son los mismos, aunque el orden sea distinto.

¿Qué significan los colores en la comparación?

El verde indica adiciones y el rojo indica eliminaciones. Se resalta toda la línea modificada, mientras que el segmento exacto que cambió se destaca con mayor intensidad.

¿El orden de las propiedades afecta al resultado?

No. Las propiedades se ordenan alfabéticamente antes de la comparación, por lo que los objetos con el mismo contenido pero con un orden de propiedades diferente se consideran equivalentes.

Izquierda
{"a": 1, "b": 2}
Derecha
{"b": 2, "a": 1}

Equivalentes: el orden de las propiedades no afecta a la comparación.

¿El orden de los arrays afecta al resultado?

No. Smart JSON Diff encuentra automáticamente la mejor forma de alinear los elementos de los arrays, por lo que los arrays que contienen los mismos elementos en un orden diferente se consideran equivalentes.

Izquierda
[
  {
    "id": 1,
    "name": "Ana"
  },
  {
    "id": 2,
    "name": "Sam"
  }
]
Derecha
[
  {
    "id": 2,
    "name": "Sam"
  },
  {
    "id": 1,
    "name": "Ana"
  }
]

Equivalentes: cada objeto conserva sus valores, aunque cambie su orden en el array.

¿Cómo se gestionan las diferencias entre arrays?

Smart JSON Diff encuentra una alineación que maximiza la similitud entre las dos versiones. Cuando ambos arrays contienen una clave única, los elementos se alinean mediante esa clave; de lo contrario, se alinean mediante su contenido normalizado. Esto ayuda a minimizar el ruido y a destacar los cambios más relevantes. Reordenar los mismos elementos no produce ninguna diferencia, mientras que los elementos añadidos, eliminados o modificados siguen detectándose.

¿Qué ocurre con duplicados y valores modificados?

Los duplicados siguen contando y se detectan valores diferentes aunque la estructura sea la misma.

Izquierda
[1, 1, 2]
Derecha
[1, 2]

Diferentes: el lado izquierdo contiene una aparición más del número 1.

Izquierda
{"value": 10}
Derecha
{"value": 20}

Diferentes: el campo contiene 10 a la izquierda y 20 a la derecha.

¿Es seguro pegar datos confidenciales?

La comparación se realiza en el navegador. Las entradas y los resultados pueden permanecer en localStorage; consulte la página de privacidad sobre almacenamiento y servicios externos.
