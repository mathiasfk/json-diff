Privacidade

A comparação ocorre no navegador. A ferramenta salva textos, formatos selecionados, estado da tela e resultado no localStorage para restaurá-los; a escolha de idioma também é salva. Limpe os dados do site no navegador para removê-los.

O site usa o Google Analytics e envia eventos de uso, incluindo ações, formatos, contagens de caracteres e alguns metadados de arquivos (incluindo nomes de arquivos rejeitados); o código desses eventos não envia o texto das entradas. O Google recebe requisições ao carregar o Analytics. O editor também pode carregar recursos de uma CDN. Considere o navegador, as extensões e o dispositivo antes de inserir dados sensíveis. A hospedagem no GitHub Pages também envolve requisições ao GitHub. Nenhum anúncio é carregado atualmente.
